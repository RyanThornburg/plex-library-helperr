Radarr and Sonarr send this with their webhooks. It's only accepted on the webhook, which starts movers; everything else needs your Cloudflare Access sign-in.

Regenerating stops the old key working right away, paste the new one into Radarr and Sonarr.

Radarr / Sonarr webhook

Movers run as soon as a movie or series is added, so it moves to its root folder before anything downloads. Keep a movers schedule (e.g. daily) as a safety net.

In Radarr and Sonarr: Settings → Connect → + → Webhook.

Triggers
Radarr: On Movie Added. Sonarr: On Series Add. Others are accepted and ignored.
URL
http://plex-library-helperr:{{ port }}/webhooks/arr (this container's name on the shared Docker network)
Method
POST
Headers
X-Api-Key = the API key above
Username / Password
leave empty

Versions without a Headers field can send the key as the Password instead, with any Username.

The Test button in Radarr/Sonarr should succeed without starting a run.
