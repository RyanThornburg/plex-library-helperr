API key

Radarr, Sonarr, Kometa and Tautulli send this with their webhooks. It's only accepted on the webhooks, which start movers and record Kometa's runs and Plex sessions; everything else needs you to sign in.

Regenerating stops the old key working right away, paste the new one into Radarr, Sonarr, Kometa's config.yml and Tautulli's webhook URL.

Radarr / Sonarr webhook

Movers run as soon as a movie or series is added, so it moves to its root folder before anything downloads. Keep a movers schedule (e.g. daily) as a safety net. An upgrade leaves the old file in Plex's trash, so a follow-up empty trash runs once Plex has scanned (Settings → General).

In Radarr and Sonarr: Settings → Connect → + → Webhook.

Triggers
Radarr: On Movie Added. Sonarr: On Series Add. Both: On File Import and the On File Upgrade under it (only upgrades are used, other imports are ignored). Others are accepted and ignored.
URL
http://plex-library-helperr:{{ port }}/webhooks/arr (this container's name on the shared Docker network)
Method
POST
Headers
X-Api-Key = the API key above (an advanced field: turn on Show Advanced to see it)
Username / Password
leave empty

Or send the key as the Password, with any Username: both work the same.

The Test button in Radarr/Sonarr should succeed without starting a run.

Kometa webhooks

Kometa has no API, so it tells Helperr about its runs instead: when each starts and finishes, what it changed, and its errors, such as a list that no longer exists or a filter Kometa doesn't know. The Status page shows them, and warns when no run has finished for well over the usual time between runs.

In Kometa's config.yml, under webhooks:

{% set url = "http://helperr:" ~ api_key ~ "@plex-library-helperr:" ~ port ~ "/webhooks/kometa" %}

Kometa can't send headers, so the API key goes in the URL as its password. Kometa sends that as a login (basic auth), not in the address, and hides the URL in its own log. Leave out changes and delete: Helperr doesn't use them, and changes carries posters too large to accept.

Tautulli playback webhook

Catches someone who keeps trying a title that won't start and gives up without telling you. Tautulli leaves plays under its ignore interval (2 minutes) out of its history, but still sends notifications for them. With this webhook Helperr sees every session: a title one person couldn't start several times, or several titles on one device, is a warning on the Status page's Plex card and listed on Playback.

In Tautulli: Settings → Notification Agents → Add a new notification agent → Webhook.
